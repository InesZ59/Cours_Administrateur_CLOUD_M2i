# Exercice pratique App Service 

## Objectifs

Appréhender le fonctionnement d'App Service et des App Service Plan dans l'environnement Azure

## Sujets

Via l'utilisation du portail Azure (interface web), réaliser le déploiement d'un [applicatif](./app-nodejs.zip) de type Node.js

* Créer un groupe de ressource si ce n'est pas déjà fait
* Créer une ressource de type Web App (App Service)
* Créer au sein de l'interface un AApp Service Plan (le plan de tarification prévu étant F1 - Free)
* Attendre le déploiemennt de l'application
* Publier ensuite le code via le Centre de déploiement (menu sur la gauche dans l'interface web de la Web App)
* Redémarrer manuellement si besoin l'application de sorte à mettre à jour le rendu
