# Exercice 1 - Mise en place d'un conteneur de 2048

## Objectifs

Installer et apprendre les bases de Terraform dans la mise en place d'un conteneur Docker

## Sujet

Via un projet Terraform, vous allez réaliser deux ressources:
- Une image de conteneur Docker permettant d'avoir un conteneur du jeu 2048
- Un conteneur local fournissant un accès au jeu, dans le navigateur, via une redirection de port
