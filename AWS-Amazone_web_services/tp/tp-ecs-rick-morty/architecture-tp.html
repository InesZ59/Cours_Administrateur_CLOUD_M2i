TP Amazon ECS · région eu-west-3 (Paris)

Rick & Morty Explorer sur ECS Fargate

Architecture cible du TP : une application Spring Boot / Thymeleaf dans une tâche Fargate, joignable directement par son IP publique, sans load balancer ni base de données. Les données viennent de l'API publique rickandmortyapi.com.

Contraintes

  • ECS Fargate
  • Image dans ECR
  • Journaux dans CloudWatch
  • Health check du conteneur
  • 0,5 vCPU / 1 Go
  • Port 8080
  • Préfixe rm-
  • Load balancer
  • Base de données
  • Passerelle NAT

Missions

  1. Prendre en main l'applicationla faire tourner en local
  2. Préparer le réseaujoignable sur 8080 uniquement, sans NAT
  3. Publier l'imageECR, tag 1.0
  4. Lancer l'application sur ECS1 instance permanente, Running et Healthy
  5. Accéder à l'applicationbadge ECS visible dans le navigateur
  6. Éprouver l'architecturepanne, 2 instances, APP_ENV=production
  7. Piloter en AWS CLIétat, adresse, journaux, mise à l'échelle
  8. Nettoyerplus aucune ressource rm- facturée
