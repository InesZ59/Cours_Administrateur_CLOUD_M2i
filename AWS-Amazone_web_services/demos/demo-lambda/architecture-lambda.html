Démo AWS Lambda · région eu-west-3

Gestion de commandes 100 % serverless

Trois fonctions Lambda déclenchées de trois manières différentes : par une requête HTTP (API Gateway), par le dépôt d'un fichier (S3) et par l'horloge (EventBridge). Les données sont dans DynamoDB, les rapports dans S3. Aucun serveur, aucun VPC, rien de facturé au repos.

Trois déclencheurs, trois comportements

DéclencheurModeEn cas d'erreur
API Gatewaysynchronel'erreur est renvoyée tout de suite au client
S3asynchroneLambda réessaie 2 fois
EventBridgeasynchroneLambda réessaie 2 fois

Déroulé de la démo

  1. Construire dans la consoletable, bucket, 3 fonctions, rôles, déclencheurs
  2. Créer des commandespage web et API, validation 400
  3. Déposer les CSVtraitement en parallèle, lignes rejetées dans les logs
  4. Lire le rapportgénéré toutes les 5 minutes dans S3
  5. Exploiter en CLIversions, alias, canary, retour arrière, coupure d'urgence
