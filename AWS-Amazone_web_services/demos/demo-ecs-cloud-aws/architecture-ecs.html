Démo Amazon ECS · région us-east-1

Application Produits sur ECS Fargate

Spring Boot 4 et Thymeleaf dans deux tâches Fargate derrière un Application Load Balancer, avec une base PostgreSQL sur Amazon RDS. Image dans ECR, identifiants dans Secrets Manager, logs et métriques dans CloudWatch.

Parcours d'une requête

  1. Navigateur → ALBHTTP :80 via l'Internet Gateway, autorisé par produits-alb-sg.
  2. ALB → une des 2 tâchesTarget group produits-tg de type IP, port 8080. Le pied de page affiche le conteneur qui a répondu.
  3. Tâche → RDSJDBC :5432 vers produits-db en sous-réseau privé, avec les identifiants injectés depuis Secrets Manager.
  4. Au démarrage de chaque tâcheECS (rôle d'exécution) télécharge l'image depuis ECR, lit le secret et envoie les logs vers /ecs/produits.

Ce que la démo montre

  • Répartition de charge entre 2 conteneurs
  • Mise à jour progressive v1.0 → v2.0 sans coupure
  • Auto Scaling de 2 à 6 tâches sur le CPU
  • Circuit breaker et retour arrière automatique
  • ECS Exec : shell dans un conteneur
  • Redémarrage RDS : erreurs 500 puis reprise seule
