# Exercice Docker #1 - Jeu 2048

## Objectifs

Appréhender la recherche et le déploiement d'images de conteneurs Docker

## Sujet

Via les commandes de base de Docker vues en cours, réaliser le déploiement et la mise en place d'un conteneur Docker permettant:
* D'accéder à un serveur web
* D'avoir en guide de page d'accueil le jeu 2048

Pour cela, il faudra:
* Trouver une image du jeu 2048 sur DockerHub
* Inspecter l'image ou en lire la documentation pour en extraire les information utiles à son déploiement
* Récupérer l'image localement
* Déployer un conteneur à partir de cette image 
* Vérifier le déploiement via notre navigateur 
* Enjoy !

## Correction 

* Trouver une image du jeu 2048 sur DockerHub

```bash
docker search 2048
```

* Récupérer l'image localement

```bash
docker pull quchaonet/2048
```

* Inspecter l'image ou en lire la documentation pour en extraire les information utiles à son déploiement

```bash
docker inspect quchaonet/2048
```

* Déployer un conteneur à partir de cette image 

```bash
docker run -d -p 80:8080 quchaonet/2048
```

* Vérifier le déploiement via notre navigateur 

```bash
curl http://localhost:80
```

* Enjoy !
